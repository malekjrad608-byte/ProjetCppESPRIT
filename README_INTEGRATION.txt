ANIWORLD2 — Integration Employés + Locaux

Interface conservée à l’identique.
Modules fonctionnels intégrés :
- Employés
- Locaux

Les boutons Tableau de bord, Services, Stock et Dossiers médicaux restent visibles pour conserver l’interface originale, mais leurs intégrations ne sont pas incluses dans cette version.

Connexion :
- LINDA / LINDA123 -> ouvre Employés
- EMNA / EMNA123 -> ouvre Locaux

Stockage :
- Employés : aniworld.db
- Locaux : données locales du module

Compilation sous Qt Creator :
1. Ouvrir ANIWORLD2.pro
2. Choisir un kit Qt 6.x + MinGW 64 bits compatible
3. Exécuter qmake
4. Compiler puis lancer ANIWORLD2
