ANIWORLD — Employes / Oracle / Qt 6.7
====================================

CONFIGURATION ORACLE
--------------------
Le projet utilise QODBC (connexion ODBC 64 bits) et les parametres suivants
sont dans connection.cpp :
  DSN      : Source_Projet2A
  Service  : localhost:1521/XEPDB1 (dans le DSN ODBC)
  Utilisateur : EMPLOYES
  Mot de passe : Tunisie2024

Si votre configuration est differente, adaptez ODBC_DSN, DB_USER et DB_PASS.
Le compte Oracle doit avoir CREATE SESSION, CREATE TABLE, CREATE SEQUENCE,
CREATE TRIGGER et un quota suffisant sur son tablespace.

DEMARRAGE DANS QT CREATOR
-------------------------
1. Verifiez que le service Oracle est demarre.
2. Ouvrez la source ODBC 64 bits et testez Source_Projet2A. Elle doit viser
   localhost:1521/XEPDB1 (ou le service de votre installation).
3. Ouvrez ANIWORLD2.pro avec Qt Creator.
4. Faites Build > Run qmake, puis Rebuild, puis Run.
5. En haut de l'application, le badge Oracle doit afficher « Oracle connecté ».
   S'il affiche « Oracle non connecté », cliquez dessus pour retenter. Le
   message d'erreur indique si le probleme vient du DSN, du compte ou du schema.

CREATION / PREPARATION DES TABLES
---------------------------------
Au demarrage, le programme verifie et prepare les tables EMPLOYES,
PLANNING_AFFECTATIONS et EMPLOYE_EVALUATIONS dans le schema de l'utilisateur connecte. Il ne supprime
aucune donnee. Si une table existe deja, les colonnes optionnelles attendues
qui manquent sont ajoutees. Le code verifie aussi le generateur de l'ID :
sequence + trigger, sauf si la colonne ID est de type IDENTITY Oracle ou si un
trigger actif genere deja :NEW.ID.

Pour une nouvelle base, la table EMPLOYES utilise DATE_EMBAUCHE de type DATE.
Le code accepte aussi une ancienne table ou DATE_EMBAUCHE est VARCHAR2(10).
Les donnees existantes ne sont pas supprimees ni converties automatiquement.
Si la table existante ne contient pas ID, NOM ou PRENOM, l'application affiche
un message explicite : verifiez cette structure dans Oracle SQL Developer.

TESTER L'AJOUT D'UN EMPLOYE
---------------------------
1. Lancez l'application : la page Employés est la page principale (le menu Tableau de bord a été retiré).
2. Cliquez sur « Ajouter un employé », remplissez au minimum Nom et Prénom.
3. Cliquez « Ajouter ». Si l'enregistrement reussit, la liste est actualisee.
4. Dans Oracle SQL Developer, connectez-vous au meme utilisateur et service,
   puis executez :

   SELECT ID, NOM, PRENOM, COURRIEL, TELEPHONE, POSTE, DATE_EMBAUCHE,
          DISPONIBLE, CHARGE_HEBDO, DISPO_HEBDO, COMPETENCES
   FROM EMPLOYES
   ORDER BY ID DESC;

Les opérations CRUD passent par le modele Employe (employe.cpp) et sont exécutées
dans Oracle via la connexion Qt partagée. Le modèle revalide les champs, contrôle
les courriels déjà utilisés (sans distinguer majuscules/minuscules), et signale aussi
une modification ou suppression qui ne concerne aucune ligne.
Les erreurs Oracle (courriel deja utilise, probleme de colonne, de droits, etc.)
sont affichees dans l'application au lieu d'afficher un faux succes.

VERIFIER LES 4 OPERATIONS CRUD
------------------------------
1. READ : au demarrage, les fiches employes sont chargees depuis EMPLOYES. La
   recherche accepte le nom, le prenom, l'ID, le courriel et le poste ; les filtres
   par poste et disponibilite ainsi que le tri actualisent la liste depuis Oracle.
2. CREATE : ajoutez un employe, puis relancez dans SQL Developer le SELECT ci-dessus.
   La nouvelle ligne doit apparaitre avec son ID genere par la sequence/trigger.
3. UPDATE : selectionnez cette fiche, modifiez un champ et cliquez Modifier.
   Le meme ID doit etre present dans Oracle avec la nouvelle valeur.
4. DELETE : supprimez cette fiche et confirmez. Le SELECT ne doit plus retourner
   cette ligne. Les erreurs de contrainte Oracle sont affichees sans faux succes.

Les changements de disponibilite utilisent egalement un UPDATE Oracle. Apres
chaque operation, la liste et les statistiques de l'interface sont rechargees.


NOUVELLES INTERFACES EMPLOYES
----------------------------
- Le bouton « Voir les statistiques » affiche maintenant une courbe comparant
  la charge hebdomadaire et les heures disponibles pour chaque employe.
  Le graphique est dessine avec QPainter : aucun module Qt Charts supplementaire
  n'est necessaire.
- Le bouton « Performance & Evaluation », place a cote des statistiques, ouvre
  d'abord une liste d'employes avec quatre cartes en haut (nombre d'employes,
  charge totale, charge moyenne et charge maximale), puis la barre de recherche.
  Un clic sur un employe ouvre sa fiche d'evaluation professionnelle.
- Le responsable attribue une note de 1 a 5 a six criteres : discipline,
  comportement/communication, competences professionnelles, qualite du travail,
  hygiene/securite et responsabilite/travail en equipe. Il peut aussi saisir les
  points forts, axes d'amelioration, commentaire general et objectifs.
- Les evaluations sont conservees dans EMPLOYE_EVALUATIONS. Chaque sauvegarde
  cree une nouvelle entree, ce qui permet de garder un historique.
- Avant selection, seul le bouton Fermer est visible. Apres selection d'un
  employe, les boutons PDF et Gmail deviennent visibles et actifs, meme si la
  fiche n'a pas encore ete sauvegardee. Le PDF exporte le contenu actuellement
  affiche. Gmail ouvre un brouillon pre-rempli avec le destinataire et le contenu
  actuellement affiche ; le responsable verifie le message puis clique sur
  Envoyer. Le PDF peut etre ajoute en piece jointe depuis Gmail. L'envoi
  automatique avec piece jointe necessiterait une configuration OAuth Gmail.
- Le bouton « Enregistrer l'evaluation dans Oracle » conserve une version dans
  l'historique ; les modifications non sauvegardees peuvent tout de meme etre
  exportees en PDF ou copiees dans un brouillon Gmail.

RECONSTRUCTION APRES MODIFICATION
--------------------------------
Qt Creator > Build > Run qmake > Rebuild > Run.

CONSULTER LES EVALUATIONS DANS ORACLE
-----------------------------------
Pour consulter l'historique enregistre :

   SELECT ID, EMPLOYE_ID, DATE_EVALUATION, EVALUATEUR, DISCIPLINE,
          COMPORTEMENT, COMPETENCES, QUALITE, HYGIENE, RESPONSABILITE,
          NOTE_GLOBALE, POINTS_FORTS, AXES_AMELIORATION, COMMENTAIRES, OBJECTIFS
   FROM EMPLOYE_EVALUATIONS
   ORDER BY DATE_EVALUATION DESC, ID DESC;
